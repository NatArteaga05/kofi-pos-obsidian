# SPEC-002 RF-12 — Datos que se conservan

Especificación: [[SPEC-002 Menú|SPEC-002]] · Historia: [[SPEC-002 HU-2 — Sacar del menú lo que no se ofrece|HU-2]]

- El sistema deberá conservar todas las categorías y productos creados, activos o inactivos: no ofrece la opción de eliminarlos.
- El sistema deberá tener en cuenta las categorías y los productos inactivos al comprobar que un nombre no se repite ([[SPEC-002 RF-3 — Crear y renombrar una categoría|RF-3]], [[SPEC-002 RF-6 — Validación de un producto|RF-6]]).

## Decisiones que lo resuelven

_Ninguno._
