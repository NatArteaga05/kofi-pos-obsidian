# SPEC-002 RF-11 — Categorías inactivas

Especificación: [[SPEC-002 Menú|SPEC-002]] · Historia: [[SPEC-002 HU-2 — Sacar del menú lo que no se ofrece|HU-2]]

- Mientras una categoría esté inactiva, el sistema deberá no permitir crear productos en ella ni mover productos hacia ella ([[SPEC-002 RF-4 — Crear un producto|RF-4]], [[SPEC-002 RF-5 — Editar un producto|RF-5]], [[SPEC-002 RF-6 — Validación de un producto|RF-6]]).
- Mientras una categoría esté inactiva, el sistema deberá permitir cambiar su nombre ([[SPEC-002 RF-3 — Crear y renombrar una categoría|RF-3]]).
