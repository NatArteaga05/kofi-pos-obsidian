# SPEC-002 RNF-2 — Importes exactos

Especificación: [[SPEC-002 Menú|SPEC-002]]

Los precios se guardan y se muestran exactamente como se escribieron, con dos decimales: «12,5» se guarda como 12,50 y nunca aparece como 12,49 o 12,500.
