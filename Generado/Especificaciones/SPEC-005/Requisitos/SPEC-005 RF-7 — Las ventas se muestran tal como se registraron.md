# SPEC-005 RF-7 — Las ventas se muestran tal como se registraron

Especificación: [[SPEC-005 Historial y reportes|SPEC-005]] · Historia: [[SPEC-005 HU-1 — Consultar las ventas de un día|HU-1]]

- El sistema deberá mostrar cada venta y calcular cada cifra con los datos de cada venta tal como se registró ([[SPEC-003 Ventas|SPEC-003]], [[SPEC-005 RF-11 — Elegir el mes|RF-11]]), aunque después haya cambiado el menú o haya cambiado o se haya eliminado la cuenta que la registró.
- El sistema deberá consultar el Historial sin modificar ninguna venta registrada.
