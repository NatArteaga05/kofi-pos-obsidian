# SPEC-003 RNF-4 — Uso con teclado

Especificación: [[SPEC-003 Ventas|SPEC-003]]

Se puede armar y registrar una venta solo con teclado: llegar a cada producto, a cada opción de las líneas y al medio de pago, y elegirlos con Intro o la barra espaciadora.
