# SPEC-007 RF-9 — Ventas como cualquier otra

Especificación: [[SPEC-007 Ventas de demostración|SPEC-007]] · Historia: [[SPEC-007 HU-1 — Llenar una base con tres meses de ventas variadas|HU-1]]

- El sistema deberá dejar las ventas de demostración igual que si se hubieran registrado desde «Nueva venta»: forman parte de las ventas registradas que se entregan a otros módulos ([[SPEC-003 Ventas|SPEC-003]], RF-11), y el Historial ([[SPEC-005 Historial y reportes|SPEC-005]]) y el Dashboard ([[SPEC-004 Dashboard|SPEC-004]]) las muestran y las cuentan como cualquier otra.
- El sistema deberá no cambiar el menú ni las cuentas de la base al cargar las ventas.
