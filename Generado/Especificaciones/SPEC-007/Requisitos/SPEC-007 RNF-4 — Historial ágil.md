# SPEC-007 RNF-4 — Historial ágil

Especificación: [[SPEC-007 Ventas de demostración|SPEC-007]]

Con las ventas de demostración cargadas, el Historial cumple su rapidez ([[SPEC-005 Historial y reportes|SPEC-005]], [[SPEC-007 RNF-3 — Rapidez|RNF-3]]): ningún día del período supera las 400 ventas de ese requisito ni ningún mes, las 6000.
