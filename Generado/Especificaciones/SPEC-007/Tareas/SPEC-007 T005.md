# SPEC-007 T005 [api] [US1]

✅ Hecha · [[SPEC-007 Ventas de demostración|SPEC-007]] · Fase 3 — US1: llenar una base con tres meses de ventas variadas (P1) · [[SPEC-007 HU-1 — Llenar una base con tres meses de ventas variadas|HU-1]]
